# PCConnect - 多人屏幕共享

一款基于 OBS + MediaMTX + Cloudflare 免费隧道的**多人屏幕共享**工具：创建会议生成链接，同事加入后各成员可轮流共享屏幕，实时查看共享列表并切换观看。**无需注册、无需域名、无需 API Key**。

## ✨ 功能特点
- 🖥️ **多人屏幕共享**：会议内任意成员可开始/停止共享，所有人实时看到共享列表并切换观看。
- 🗂️ **共享列表（roster）**：谁在共享一目了然，点击即切换画面。
- 🔗 **零门槛加入**：创建会议生成链接，同事粘贴链接即可加入，无需任何网络配置。
- 💰 **永久免费**：基于开源组件，无次数限制，无月费。
- 🎨 **多款皮肤**：内置深色和赛博朋克皮肤，一键切换。

## 📥 安装
1. 从 [GitHub Releases](https://github.com/MondayV/screen-share/releases) 下载最新安装包（如 `pc-connect-2.5.0-setup.exe`）。
2. 双击安装（安装程序会自动创建桌面快捷方式）。
3. 安装完成后，桌面会出现 `PC Connect` 图标。

> ⚠️ 应用为单实例运行（同一台电脑只能打开一个窗口），主持人端与参会端需分别在不同设备上使用。

## 🚀 使用教程

### 作为主持人（创建会议）
1. **安装 OBS Studio**：从 [obsproject.com](https://obsproject.com/) 下载并安装 OBS。
2. **启动 PCConnect**，点击 **"创建会议"**。
3. 应用会自动在后台启动 MediaMTX 和 cloudflared 隧道，生成**会议链接**并复制到剪贴板。
4. 将会议链接发给同事（微信/邮件等）。
5. 点击 **"开始共享"** 共享你的屏幕（已连接 OBS WebSocket 时自动配置推流；也可在 OBS 中手动填写 `rtmp://localhost:1935` 与显示的密钥）。
6. 结束时点击 **"停止共享"**，并点击 **"退出会议"** 关闭房间。

### 作为参会人（加入会议）
1. 启动 PCConnect，点击 **"加入会议"**。
2. 粘贴主持人发来的**会议链接**，点击 **"加入会议"**。
3. 左侧"参会人"列表实时显示共享画面，**点击任意一路即可切换观看**。
4. 需要共享自己的屏幕时，点击 **"开始共享"**（你的画面会出现在所有参会人的列表中）。
5. 结束观看点击 **"退出会议"**。

> 💡 多人共享 = 谁共享谁开一个 PCConnect 实例加入同一会议；每路共享独立推流，互不影响。

### OBS 使用注意事项
- 以管理员身份运行 OBS 可避免部分游戏黑屏或无法捕获的问题。
- 如果共享游戏，推荐使用"游戏采集"模式，性能更优。
- 网络不稳定时可降低 OBS 输出比特率（设置 → 输出 → 视频比特率，建议 2000-4000 Kbps）。

### 画质选择
在会议界面的"我的共享"中可选择推流画质（参考腾讯会议模式，切换后在下次开始共享时生效）：
- **流畅度优先**：低码率（约 1.2Mbps），网络差时更稳定
- **智能（推荐）**：中码率（约 3Mbps）+ OBS 网络自适应，根据网络状况自动调整
- **清晰度优先**：高码率（约 6Mbps），画面更清晰

### 画质优化建议
- **编码器**：如果你的电脑有独立显卡，请在 OBS 的 `设置 -> 输出` 中将编码器切换为 `NVENC` 或 `QuickSync`，可显著降低 CPU 占用并提升画质。
- **缩放算法**：在 OBS 的 `设置 -> 视频` 中，将"缩小算法"设置为 `Lanczos`，可获得更清晰的屏幕共享画面。
- **网络优化**：应用已自动配置 OBS 关键帧间隔 1 秒与动态比特率，兼顾低延迟与网络自适应。

### 一键推流（Python 脚本，推荐）
1. **打开脚本文件夹**：在 PCConnect 界面点击 **"📂 打开 OBS 脚本文件夹"**，复制其中的 `pc-connect-auto-push.py`。
2. **放入 OBS 脚本目录**：将脚本复制到 OBS 的脚本目录（Windows 路径：`%APPDATA%\obs-studio\scripts`）。
3. **在 OBS 中添加脚本**：打开 OBS → **工具 → 脚本** → 点击 **"+"** 号 → 选择刚才复制的 `pc-connect-auto-push.py`。
4. **开始共享**：在 PCConnect 中点击 **"开始共享"**，然后在 OBS 脚本界面点击 **"开始推流（自动配置）"** 即可推流，无需手动填写密钥。

> 提示：脚本会修改 OBS 的推流服务配置（`rtmp_custom`），再次手动推流前请检查推流设置。

## 🔐 安全与隐私
- **链接即密钥**：播放链接中携带流密钥，**任何拿到链接的人都能观看你的屏幕**，请仅在可信范围内分享，结束后及时停止推流。
- **本地优先**：视频流仅在本机 MediaMTX 处理，经 Cloudflare 临时隧道转发；应用无遥测、无账号、不收集任何统计数据。
- **OBS 密码**：使用操作系统级加密（Windows DPAPI / macOS Keychain）存储。
- 详细说明见 [隐私政策](PRIVACY.md) 与 [服务条款](TOS.md)。
